# Управление трактором Т43

Код предназначен для модели погрузчика на STM32. Сейчас он связывает готовые команды с тремя каналами PWM таймера TIM1.

## Что управляется

| Канал | Механизм | Действие |
| --- | --- | --- |
| TIM1 CH1 | Ход | Движение трактора |
| TIM1 CH2 | Рычаги подъёма ковша | Подъём и опускание ковша вместе с рычагами |
| TIM1 CH3 | Поворот ковша | Наклон ковша для захвата и выгрузки |

При команде движения программа устанавливает значение PWM 700 при периоде 999; при остановке — 0. Каналы запускаются при инициализации. Мощность пока фиксированная. Поворот руля в коде предусмотрен, но к оборудованию не подключён.

В исходных названиях команд и функций слово `BOOM` обозначает рычаги подъёма ковша, а `BUCKET` — наклон самого ковша. Эти имена сохранены для совместимости с исходным кодом.

## Как проходит команда

Готовая команда передаётся в `Tractor_OnUartCommand()`. В главном цикле `Tractor_Process()` обрабатывает её и передаёт состояние привода модулю `tractor_pwm`. Модуль меняет PWM нужного канала. Например, `TRACTOR_CMD_DRIVE_FORWARD` включает PWM хода, а `TRACTOR_CMD_DRIVE_STOP` устанавливает его в ноль.

Сам приём и разбор команд UART в проекте ещё не реализованы. Обработчик хранит только одну ожидающую команду: следующая может перезаписать предыдущую до обработки.

## Что ещё необходимо подключить

- **Направление моторов.** Функция `TractorBoard_SetDirection()` пока пустая. Вперёд и назад устанавливают одинаковый PWM, а физическое направление не переключается.
- **Руль и концевые датчики.** Функции `TractorBoard_SetSteering()` и `TractorBoard_SensorActive()` — заглушки. Ограничение движения на настоящих датчиках пока не работает.
- **Выводы платы.** Нужно указать и настроить выводы PWM, в том числе CH2 и CH3 в `HAL_TIM_MspPostInit`, и проверить поддержку каналов выбранным STM32.
- **UART и протокол.** Нет приёма пакетов, задания мощности командой, остановки при потере связи и телеметрии.

Для настройки нужны полный проект STM32CubeIDE или файл CubeMX `.ioc`, схема платы и сведения о драйверах моторов. Не подключайте моторы до настройки и проверки драйверов и концевиков.

## Файлы проекта

- `src/main.c` — запуск программы, настройка TIM1, назначение каналов и главный цикл.
- `src/tractor_top.c` и `src/tractor_top.h` — команды и логика управления трактором.
- `src/tractor_pwm.c` и `src/tractor_pwm.h` — связь логики управления с PWM-каналами.
- `tests/` — проверки на компьютере с программной имитацией STM32 HAL.

Полного проекта STM32CubeIDE, настоящего `main.h`, HAL и настроек платы в репозитории пока нет.

## Проверка на компьютере

Тесты запускают код с имитацией таймера. Они проверяют обработку команд, изменение PWM, остановку и один из сценариев концевика. `test_main.c` также проверяет запуск программы из `main.c`. Тесты не проверяют UART, физические выводы и двигатели.

Из корня репозитория в PowerShell при установленном GCC:

```powershell
New-Item -ItemType Directory -Force build-test | Out-Null
gcc -std=c11 -Wall -Wextra -Werror -I tests -I src src/tractor_top.c src/tractor_pwm.c tests/test_pwm.c -o build-test/test_pwm.exe
if ($LASTEXITCODE -ne 0) { throw 'Ошибка сборки test_pwm' }
./build-test/test_pwm.exe
if ($LASTEXITCODE -ne 0) { throw 'Ошибка test_pwm' }
gcc -std=c11 -Wall -Wextra -Werror -DTEST_FULL_MAIN -Dmain=firmware_main -DTractor_Process=Test_Process -I tests -I src -c src/main.c -o build-test/main.o
if ($LASTEXITCODE -ne 0) { throw 'Ошибка сборки main.c' }
gcc -std=c11 -Wall -Wextra -Werror -DTEST_FULL_MAIN -I tests -I src src/tractor_top.c src/tractor_pwm.c tests/test_main.c build-test/main.o -o build-test/test_main.exe
if ($LASTEXITCODE -ne 0) { throw 'Ошибка сборки test_main' }
./build-test/test_main.exe
if ($LASTEXITCODE -ne 0) { throw 'Ошибка test_main' }
```
